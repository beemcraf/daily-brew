❓ หัวข้อที่ 12: ชุดคำถามวินิจฉัยความต้องการลูกค้า (Diagnostic Questions)

กำหนดให้ AI Chatbot ถามลูกค้ารวม 4 คำถามเพื่อคัดกรองความชอบและบริบท:

คำถามที่ 1: ความชอบด้านรสชาติกาแฟ
"วันนี้อยากดื่มกาแฟเข้มข้นตื่นเต็มตา, กาแฟผลไม้สดชื่น, หรือเป็นเครื่องดื่มไม่ผสมกาแฟดีคะ?"
(ตัวเลือก: เข้มมันครีมมี่ / สดชื่นเปรี้ยวหวาน / Non-Coffee ชา-โกโก้)
คำถามที่ 2: เนื้อสัมผัสและประเภทนม
"ชอบดื่มแบบผสมนมสดหอมมัน, นมโอ๊ตสุขภาพ หรือชอบแบบกาแฟดำสกัดเย็นคะ?"
(ตัวเลือก: นมสดแท้ / นมโอ๊ต Plant-Based / กาแฟดำ)
คำถามที่ 3: ระดับความหวาน
"ชอบความหวานระดับไหนดีคะ ร้านปรับได้ตั้งแต่ 0% ถึงหวานปกติ 100% เลยค่ะ"
(ตัวเลือก: ไม่หวาน 0% / หวานน้อย 25-50% / หวานปกติ 100%)
คำถามที่ 4: ความถี่ในการดื่ม & งบประมาณ
"สั่งดื่มแก้วเดี่ยว หรือดื่มเป็นประจำ สนใจดูแพ็กเกจรายเดือนประหยัด 40% ด้วยไหมคะ?"
(ตัวเลือก: สั่งแก้วเดี่ยว 100-140฿ / สนใจแพ็กเกจประหยัด 40%)

⚙️ หัวข้อที่ 13: กฎในการแนะนำสินค้า (Rule-Based Recommendation Logic)

RULE 1: IF ลูกค้าชอบ กาแฟเข้มข้น + หอมมันนม + ไม่เปรี้ยว → THEN: แนะนำ Signature Dirty Coffee (120฿) ชูจุดเด่นนมสูตรลับเย็นจัดกับเอสเปรสโซสกัดร้อน แยกส่งอย่างดี
RULE 2: IF ลูกค้าชอบ สดชื่น + ตื่นตัว + ผลไม้เปรี้ยวซ่า → THEN: แนะนำ Sparkling Yuzu Tonic (130฿) หรือ Artisan Orange Cold Brew (135฿)
RULE 3: IF ลูกค้า แพ้นมวัว / ทานเจ / สายสุขภาพคลีน → THEN: แนะนำ Vanilla Bean Oat Latte (130฿) หรือ Coconut Cloud Espresso (125฿)
RULE 4: IF ลูกค้า ไม่ดื่มกาแฟ + ชอบรสเข้มข้น → THEN: แนะนำ Valrhona Dark Chocolate Float (135฿) ช็อกโกแลตฝรั่งเศส 70%
RULE 5: IF ลูกค้า สั่งเครื่องดื่มแล้ว และถามหาของหวานคู่กัน → THEN: แนะนำเซ็ตโปรโมชั่น Work & Chill Combo (179฿) คู่กับ Basque Cheesecake หรือ Almond Croissant
RULE 6: IF ลูกค้า ดื่มประจำเกือบทุกวัน / ถามหาโปรโมชั่น → THEN: แนะนำ Daily Brew Pass (10+2 แก้ว เพียง 990฿) ประหยัด 40% และฟรีอัปเกรดนมพืช
RULE 7: IF ลูกค้า ต้องการเมล็ดกาแฟไปชงเองที่บ้าน → THEN: แนะนำ เมล็ดกาแฟดอยช้าง Peaberry 250g (280฿) คั่วสดใหม่พร้อมบริการบดฟรี
